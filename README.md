# KBC Arena
A browser-based KBC-inspired quiz game built with Next.js, TypeScript and Tailwind CSS.

- Guest play by entering a name; no login or signup.
- 15 questions and a virtual ₹1 crore prize ladder.
- 45-second question timer and 50:50, audience poll and hint lifelines.
- Browser-local scores and leaderboard.
- Responsive dark navy and gold interface.

## Run locally
`npm install`
`npm run dev`

Scores are stored in localStorage and are limited to the current browser/device. No server-side leaderboard or admin CMS is included in this first release. All prizes are virtual.
